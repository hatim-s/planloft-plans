Core API handoff

Authoritative schemas and inferred types live in src/shared/contracts.ts. Route handlers live in src/server/http behind the core request guards. Mutations require loopback access, allowed origin and JSON with bounded bodies. No route is a generic shell, gh or MCP proxy.

Project and tickets

GET /api/project returns config, runtimeId, configPending and historicalState. POST /api/project/reload rereads the manifest and applies policy when ownership permits. It cannot reidentify a running project. POST /api/core/config is removed.

GET /api/core/snapshot, POST /api/core/tickets, and POST /api/core/tickets/:id/cancel expose ticket state and intent. Enqueue is schema-decoded once, repository-bound, with immutable specification/revision/scope and at least one required check. Unknown categories fail admission. Cancellation remains intent until ownership is confirmed ended.

CoreStore owns synchronous transitions, operation CAS and durable records. CoreStorage.open is scoped. CoreDaemon owns serialized ticks and its scoped worker. OperationWorker advances explicit per-kind executors. Claims, leases and named transitions are coordinator internals. A stale CAS must prevent another local send; it does not revoke remote work already dispatched.

Read actual schemas for dossier variants, bounds and errors. Same-repository resolution is explicit. Keep comment/close state separate. Fresh remote observations do not rewrite terminal history. Scope and full closure/reopen timeline matter after uncertainty; event absence never authorizes blind retry.

GitHubTransport uses argv through runProcess, without a shell. HTTP mutation classification distinguishes applied, rejected and uncertain. Keep repository/head/check/run/attempt identities in evidence. A fetched ref is local evidence. Issue body replacement stays observation-only in the host adapter because it has no remote conditional-write fence.

The CLI is bun run factory; it prints JSON and nonzero errors. Read src/server/cli.ts for current flags. Publication authorization is committed policy plus the configured authorized operator command. An optional host policy may restrict it. The current CLI still contains a legacy docs authorize branch, but no matching authorization route is mounted. Do not use that command as an operating prerequisite.

DocPublisher exports git source, computes revision identity, renders through PlanloftRunner, and persists publication intent before invoking the worker. Render receipts include revisionId, artifactSha256, bytes, path, dirty, commit and files. planloft-worker.ts calls the pinned 1.0.1 application API. MDX trust is explicit executable authorization. Render environment strips credentials. Actual MDX source dependencies are hashed conservatively across .factory/docs.

Unknown publication blocks retry and replacement until writer settlement. Matching bytes establish presence only. The implementation currently returns writer_unsettled without a general remote recovery protocol. Do not infer commit ancestry from timestamps or manufacture supersession authority.

T3

docs/t3-connection.md is the S6 operating contract. T3Transport.scoped initializes MCP and paginated schema discovery. T3Connection.execute exposes attach, read, configuration, questions, launch, send, cancel, respond and task_cancel. Writes claim durable intent through the host and CoreStore. Local fixture claims alone are not durable production evidence.

http/t3.ts provides GET /api/t3/status, GET /api/t3/config and POST /api/t3/actions. Current source mounts them when optional manifest t3.connectionRef is present and resolves machine configuration through FACTORY_T3_CONNECTIONS. CLI status/config/execute and shared action schemas are wired. This bootstrap omits a connection reference until the machine binding exists. Source integration is not accepted live behavior.

Endpoint/auth/OAuth renewal are machine-owned. Local status is not active health. Questions can be listed and a response action is wired; permission approvals stay in T3 UI. Response behavior still needs live acceptance. Model/options are explicit and checked against returned launch configuration; catalog preflight is incomplete. No shadow transcript or automatic reconnect replay is allowed. Deduplication, authoritative absence and descendant termination remain unproven across sessions, so dependent unattended operations retain ownership or stay gated. Read-only and supported explicit operations need not be globally blocked.
