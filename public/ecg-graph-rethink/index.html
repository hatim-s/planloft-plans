    4 · Where the groups come from

    No hand-made categories

    Every grouping on this page is computed from the exported relationships. Groups are communities found by the Louvain method on the type-to-type links, and each is named after its most connected type. Similar types are types whose relationships overlap by at least 60%; most mocks draw each set as one node, and the tooltip lists its members. In this export every type has the category Core, and the API gives no link between types and source systems, so neither can separate anything.
