Workflow Agent benchmark

Tested 35 sandbox prompts. 33 benchmark runs and two early pilots. They saved 111 workflows and deployed 103.

Large workflow edits in Orbit Builder

15 of 15 edits passed across five drafts with 300 to 400 nodes. Each draft received three prompts in the same chat. Saved graph checks confirmed every requested change and preserved previous edits, node IDs, and edges. The drafts remained undeployed and were never executed.

Average per request · 2m 01s trace latency · $0.1803 recorded LLM cost. Total cost was $2.7046.

First edits averaged 4m 30s / $0.3514. Second edits averaged 57s / $0.1231, and third edits averaged 35s / $0.0665. Each average covers five requests. First edits accounted for 75% of trace time and 65% of cost.

All 15 saves used Builder’s legacy MCP fallback after the installed bridge sent record where the chat tool expected arguments. These figures measure the live Builder experience. Performance through the dedicated MCP path remains unverified.
