Workflow Agent benchmark

Across measured runs, sandbox averaged $2.85 in Workflow Agent LLM cost per Solution versus $5.52 for legacy, with nearly identical dispatch-to-deployment time (9m 57s vs. 9m 52s).

Adopt sandbox as the default for new builds. One worker handles the whole batch and can reuse discovery and source code across workflows. Keep tracking deployment completion and latency during rollout: matched replays took longer on average, and Invoice Reconciliation drove most of the cost savings.
