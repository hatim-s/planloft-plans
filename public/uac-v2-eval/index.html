uac v2: agents building real workflows

Three models wrote the 20 ACM workflows from their briefs, with only the llm-tools MCP server as tools. Each saved workflow was then run on the tenant, and its output compared with what the dataset's reference automation returned for the same input.

Same 20 briefs, same harness, same strict scoring, same day. Only the compiler, its MCP tools and the agent prompt differ between v1 and v2. The compiler's own proof (corpus laws, gates, reviews) is the companion page.

Each cell is one run. ✓ means the output matches the reference's. ✗ means the run failed, nothing was saved, or the output differs. ~ means the output has the right shape with different values. Hover a cell to see the verdict, the brief and what the run cost.

How a run is scored

  • Each agent runs as a headless CLI in an empty directory: claude -p for Haiku 5.5, codex exec for GPT 6 Luna, opencode run for DeepSeek V4.1 Flash. HOME, CODEX_HOME and XDG point at empty directories, so no global skill, memory or repo doc reaches the agent. A recording proxy sits between the CLI and the MCP server.
  • The agent may test-run its workflow once, and never deploys. The brief's resources (objects, connections, channels) are real ones on the ACM tenant.
  • After the agent stops, the harness triggers the saved workflow with the dataset's input and triggers the reference automation with the same input, then compares the two outputs.
  • Pass is match or prose-match. Integers must be equal; other numbers may differ by a relative 1e-9. Free text is compared loosely only at paths the corpus declares as prose ($.remarks on p14, $.result on p19). A right shape with wrong values, a failed run or no saved workflow is a fail.
  • A refusal by the provider (rate limit, free-tier limit) is an infrastructure error, not a fail, and the run is retried. DeepSeek ran on the OpenCode free tier first and fell back to the Go plan when the free tier refused.

Iterations

Each iteration changed the compiler, the MCP tools or the prompt, guided by the previous run's failures. The corpus changed once: after iteration 2, three briefs (p01, p14, p20) were replaced with others from the same dataset. All points are rescored with the final comparator. Muse Spark ran in iterations 3 to 8 and was then dropped to save the OpenCode limit.

The evidence in the repository

Everything on this page comes from packages/uac/eval/evidence/2026-11-13/:

  • scores.json: the iteration trend and the per-brief matrix behind every chart here.
  • runs/<label>/<model>/<case>.json: one record per final run, with the verdict, both outputs, tool calls, time and token usage.
  • code/<label>/<model>/<case>.ts: the last source each agent compiled.
  • usage.csv: tokens and cost for every run of every iteration.

To rerun: bun eval/run.ts --label <name> --system docs/agent-prompt.md --models haiku,luna,deepseek from packages/uac, with the MCP server running from packages/llm-tools and a gitignored .local-tenant.json there.
