Round 1

Sol tested at 1440 × 900 in light mode. Changes in 4a89197b:

  • Pinned cards list every rule and scroll inside the canvas clear of controls. A rule that reaches more than three types opens into chips.
  • The node list shows record counts, sorts highest first, and includes a "No records" filter.
  • Searching a merged type notes which group opened. Clicking any card chip opens that target and offers a "Back to" link.
  • The level label opens a menu for Groups, Types, All types, and Rule names. At Groups, hovering a band lights it and its two groups.
  • A top-left key explains what solid and dashed lines mean.
  • Type cards now name real target types instead of merged labels. Opportunity names OEP and UCB.
  • Searching clears any highlighted group. Reset clears the view, pin, trail, search, filters, and highlight.
  • Focusing Support now relies on the full card. I chose not to build a neighbours-only view.

Learnings

  • Merging belongs on the canvas, not in detail cards. Cards should always name real types.
  • The checker paid for itself. Gemini corrected six claims and upheld three prior design decisions.

Round 2

Sol tested again at 1440 × 900 in light mode. Changes in 5b41731b:

  • Panned cards dock in the top-right corner and offer "Show on canvas". Reset and Unpin stay visible.
  • Type cards now list every property name from production. Pull Request shows all 23 instead of 12.
  • Clicking a group narrows the node list to its types and keeps it lit. A chip clears the filter.
  • Cards opened from a chip start at the top with every rule closed.

Learnings

  • Test layout fixes in every state. Checking only the open state missed cards sliding over Reset after a pan.
  • When numbers clash in the UI, check the data pipeline too. A derive script had capped properties at 12.

Round 3

Sol tested at 1440 × 900 and 1280 × 800 in light and dark mode. It also added a full group review task. Changes in 2625396f:

  • All types now works at 1280 × 800. Rule names start later on smaller screens.
  • The "No records" count now matches the active search and picked group. Contact shows 6, Commit shows 0, and clearing returns to 42.

Learnings

  • Fixed zoom cutoffs break on smaller screens when layouts scale. Calculate zoom thresholds from the canvas geometry.
  • Task audits find workflow gaps, not visual ones. UI stayed at 7 every round, so visual changes need their own brief.

Still open

  • At 1280 × 800, Rule names can stay hidden over the dense Feature group. Pressing plus once more reveals them.
  • I did not build a neighbours-only view. Focused types also lack tags where links leave the canvas.
  • The UI score held at 7 across all rounds, with no finding explaining why.
  • Whether node size follows link count or record count is still Hatim's call.
