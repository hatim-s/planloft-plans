Core operations

Factory admits tickets against pinned scope. T3 owns sessions and workspaces. Agent completion is an observation; acceptance also requires the configured evidence for the same candidate. Release tickets grant no merge or service deployment authority.

Start and inspect

Run from the main checkout containing .factory/factory.json:

bun run factory discover
bun run factory serve
bun run factory docs status

The manifest owns core policy. POST /api/core/config is removed. Edit the manifest and reload with POST /api/project/reload; owned attempts may keep the old policy pinned and report configPending. factory init is for new repositories, not an overwrite command. Existing clones sharing the project identity need explicit rebind when the previous checkout still exists.

Runtime is $FACTORY_DATA_DIR/projects/<projectId>/. Historical root factory.sqlite and core.sqlite are preserved and not imported. Keep ignored .factory leftovers and historical reports. Records under .factory/records are direct immutable writes, never autocommitted. Equal bytes succeed; identity conflicts preserve the old file and require inspection.

FACTORY_HOST_CONFIG selects blocked, mock or standalone adapters. Blocked is the safe default. Mock acceptance is simulated. Standalone host identity and issue mappings are machine-local. T3 endpoint/auth belong in host settings, never prompts, committed config or events. Consult docs/t3-connection.md for actual supported connection actions and missing integration.

Work and recovery

Slot selection uses priority, queue time and stable ticket ID without starvation guarantees. Attempts retain admitted scope and revision. Drift, withdrawal or deadline triggers stopping; unknown cancellation retains capacity and workspace ownership. The two-reviewer, three-round, two-repair policy does not itself prove every host can run that workflow. Local CAS fences local transitions only.

Use PR reads before submitting an explicit completion dossier:

bun run factory pr list --state all --limit 30
bun run factory pr view 42
bun run factory issue draft --ticket FAC-12
bun run factory issue resolve dossier.json
bun run factory issue status OPERATION_ID --observe

The draft is incomplete and submits nothing. Replace example IDs with actual project values. A merged PR never auto-resolves its issue. v1 requires issue and PRs in this repository. Compare reported validation with observed checks at the pinned head.

Comment and close have separate states. Unknown comment sends reconcile visible markers without automatic resend. Unknown close reconciles state, reason, full closure/reopen sequence and original intention. Missing events do not prove absence. Scope drift remains relevant during every phase and retry. A human edit can still race the last preflight read. Factory must not fight a human reopen.

Retry/cancel commands require --version CURRENT_VERSION. An operator action is not remote cancellation. Read the stored state and live observation before acting. Markers are not locks. Concurrent write-capable factories for one project on different machines are unsupported.

Documents

The manifest lists the maintained design, architecture, operations and API handoff. Author in .factory/docs; factory docs new adds an entry with publication disabled. Static TSX SVG imports require MDX plus explicit manifest trust. MDX executes code, is not sandboxed and must be reviewed. Render children omit inherited credentials.

bun run factory docs render architecture --worktree
bun run factory docs render architecture --commit FULL_IMMUTABLE_SHA

Working-tree previews are dirty and cannot be published. Commit renders export git objects. Default publication source is freshly fetched origin/base. The configured policy is manual Vercel with TTL 30. The authorized operator command is sufficient publication authorization; no confirmation is required on each read. Machine host configuration stays outside Git. The existing machine Planloft config names hatims-planloft; the lead owns final configuration and publication.

For the lead after committing and integrating the source:

bun run factory docs publish architecture --commit FULL_IMMUTABLE_SHA

Publish each desired manifest ID explicitly. A lost reply or timeout retains an unknown writer. Do not resend, supersede or publish a newer revision to that slug until the old writer safely settles or supported recovery proves safety. Local child exit is not remote cancellation. Byte equality proves content presence at observation time only. Current uncertain retries return writer_unsettled and have no general settlement recovery protocol.
