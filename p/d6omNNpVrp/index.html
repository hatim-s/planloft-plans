Source of truth for build execution. Strategy/stack rationale live in DECISIONS.md, STACK.md, ROADMAP.md — this file is the work.

Agent protocol (read first)

  1. Canonical copy lives in the planloft store: ~/.planloft/docs/attest/attest-implementation-plan.md. The repo-root PLAN.md is a gitignored local working copy — never commit it.
  2. Before starting work: sync your local copy from the store if it's newer (planloft copy attest-implementation-plan or read the store file directly).
  3. Claiming: mark an item in-progress by appending ⏳ <agent/session> <date> to its line. Do not claim items whose dependencies are unchecked.
  4. Completing: flip [ ] → [x], append ✅ <date> <agent> <one-line note or commit sha>.
  5. After any status change, rehost so all agents + the human stay updated:
    node /Users/admin/Projects/planloft/dist/cli.js hoist PLAN.md --slug attest-implementation-plan --title "attest — Implementation Plan" --kind plan
node /Users/admin/Projects/planloft/dist/cli.js deploy attest-implementation-plan
    (If planloft is on PATH, use it directly.)
  6. Scope discipline: an item = one delegable unit. If you split it, add child items under it rather than silently expanding scope. New discoveries go to the Backlog section, never inline into locked phases.
  7. Delegation hints per CLAUDE.md: [codex:luna] straightforward implementation, [codex:terra] small logic tasks, [codex:sol] large logic tasks, [opus] UI tasks, [fable] large UI or contract/design work. Orchestrator reviews all output; Opus critiques quality on merged tracks.
  8. Every item lands as a conventional commit that typechecks, lints, and passes owned tests. HITL for anything touching a real database.

Legend: dep: blocking dependencies · ∥ = parallel-safe within its track · sizes S/M/L.
