Cost and token signals

50% of output

44 of 874 LLM calls each wrote more than 5,000 tokens. Together they produced 453,578 of the 911,599 output tokens.

Calls with no cached input

$9.56 of $16.58

These calls made up 58% of combined spend. The share ranged from 44% in Store Ops SOP to 74% in Network Route Sim Hub.

Master Data Sync is still the longest run at 17m 40s, with the longest app build (10m 43s). The fastest run is now Outlook Digest at 9m 23s. Planning took over 6 minutes in three of the original six runs; the four new runs plan in 3m 12s to 5m 10s.

The app builder set the completion time in all ten runs. App builds ranged from 5m 44s (Outlook Digest) to 10m 43s (Master Data Sync); backend workflow windows ranged from 1m 09s (Network Route Sim Hub) to 5m 9s (Outlook Exec). Nine runs succeeded; Store Inventory Manager is marked partially failed.
