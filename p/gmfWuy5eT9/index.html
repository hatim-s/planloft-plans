Reading the evidence

Workflow links include the chat ID and open the exact generated conversation. Build outcomes use successful validation and persistence responses together with workflow readback. TEST success requires a native execution record and assertion evidence where assertions were configured. A returned run ID or a completed agent turn alone is not a passing test.

External sends and operational data mutations were mocked for testing. Scheduled and webhook triggers were kept inactive. Native run-indexing or test-service errors are recorded as unverified tests, with no invented pass or failure counts.

The source corpus, exact submitted prompts, amendments, per-case trace metrics, save receipts, and native test receipts are retained in the local evaluation ledger. The separate 25-prompt direct Copilot evaluation uses a different agent and is not included in these Sol totals.
