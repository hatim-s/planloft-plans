Runtime overhead: definition

What it is. Time inside one agent run when no LLM or tool span is open: LLM END → START of the tool it called (gap A), and tool END → START of the run's next LLM call (gap B). Platform time: request assembly, dispatch, result hand-back, scheduling.

What it is not. Waiting on sub-agents or the user, dispatch spans, or a stretch with no LLM span between two tool spans (Untraced).

Reproduce. Open a span on the platform, note its START, and compare with the END of the previous span in the same run. Every evidence row below links to the span.
