The eight loops

Each loop is a written procedure with a proof gate between stages. The diagrams differ because the jobs differ. A diagnosis fans out over hypotheses, a check-in crosses the platform and GitHub, and an evaluation dispatches a batch of cases. When a gate fails, work goes back to the stage that owns the fault, within a fixed retry budget.

19 skills composing the loops

18 specialist skills plus the workflow-agent router. Written in .agents/skills and linked into Claude.

workflow-agent

Route Workflow Agent developer jobs to bounded loops for trace/RCA, Atlas fixes, PR ownership, guidance repair, evaluation, asset check-in, tool contracts and compiler/workflow changes.

workflow-agent-asset-parity

Reconcile Workflow Agent canonical sources with generated, saved, and deployed assets, including skill identity/membership and requested promotion readback.

workflow-agent-atlas-maintenance

Read assigned Atlas issues, triage the queue, prove ticket symptoms, and prepare or perform explicitly requested RCA/follow-up writeback with readback.

workflow-agent-brief-corpus

Turn Workflow Agent briefs or historical prompts into a stable evaluation corpus with exact provenance, normalization, tenant preflight, and semantic acceptance.

workflow-agent-change-review

Review Workflow Agent PR intent, necessity, invariant ownership, caller effects, and security evidence against exact base/head and demonstrated behavior.

workflow-agent-changeset-import

Verify a Workflow Agent ChangeSet export before repository import, and package requested main/UAT PRs with exact artifact, scope, base/head, and readiness receipts.

workflow-agent-cohort-comparison

Compare Workflow Agent models, tenants, reasoning modes, or revisions using exact matched prompts, observed configuration, independent outcomes, and reconciled metrics.

workflow-agent-compile-cleanup

Investigate or change Workflow Agent compilation, graph lowering, cleanup validation, or compile/save failures with source-to-boundary evidence.

workflow-agent-connector-discovery

Resolve Workflow Agent connector actions and tenant/dynamic schemas, then classify connection readiness and design only consequential clarification questions.

workflow-agent-cross-layer-rca

Find the first causal break across Workflow Agent brief, prompt/skills, tool binding/schema, transport/auth, compiler/cleanup, and deployed runtime.

workflow-agent-evaluation-run

Launch a frozen Workflow Agent corpus against a named configuration using one verified pilot, bounded cohorts, and durable case/session/artifact receipts.

workflow-agent-example-corpus

Curate Workflow Agent retrievable DSL examples, connector/pagination patterns, keywords, semantic correctness, and MCP query results.

workflow-agent-mcp-contracts

Maintain Automation Code MCP exposure, input/output/error schemas, caller authority, script/full-result delivery, and deterministic read-only connector guards.

workflow-agent-outcome-proof

Independently verify a Workflow Agent completion or evaluation claim against the brief, saved/deployed graph, tests, execution, and business outputs.

workflow-agent-run-supervision

Monitor already-dispatched Workflow Agent or child runs, handle authorized clarification/recovery, and relay terminal artifacts for every case.

workflow-agent-skill-effectiveness

Verify whether a Workflow Agent prompt or runtime skill change was assigned, delivered, retained, and used to improve the intended generated behavior.

workflow-agent-skill-maintenance

Audit and edit Workflow Agent prompts, runtime skill inventory, tool descriptions, and embedded examples in their canonical owning source.

workflow-agent-trace-accounting

Verify trace exports and reports account for every model/tool call, payload, task assignment, token/cost total, and parent versus worker metric.

workflow-agent-trace-debugger

Diagnose a Workflow Agent trace or case: reconstruct the exact task journey, call attribution, stop cause, and parent-child result handoff.
