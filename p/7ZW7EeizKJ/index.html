This report compares the initial OpenAI rewrite, Workflow Split and Automation Coder on the same 25 prompt identities. Workflow Split saved the most substantive workflows, 23 of 25. Automation Coder recorded much lower model cost, but 13 saved drafts still needed repairs that could not be persisted.

The evidence supports a comparison of build persistence and tested paths. It does not support a full requirements-accuracy score: test coverage differed, some fixtures checked only empty inputs, and several reported successful runs did not establish the complete requested behavior. Snapshot: 10 September 2026. No new generations or TEST runs were launched for this comparison.

What the tests actually cover

The initial rewrite's seven latest passing paths are N02, N04, N08, N10, N11, N13 and N14. Their executed node inputs, node semantics and edges match the saved definitions. N02, N04 and N14 have zero assertions. N08 and N10 each pass 4/4 assertions. N11's final empty-URL path passes 2/2. N13 passes 1/1 but only checks a single-page implementation. N04 has a nullable-array-element contract gap, N13 lacks required pagination, and N14 omits the requested branch/condition topology. N12 also lacks pagination but has no verified final TEST pass. N06 had an earlier smoke pass followed by a hardened failure and stays failed.

Workflow Split's passing paths are 07, N05, N06, N08 and N11. Cases 07 and N06 have zero-assertion smoke coverage. N05 covers the duplicate-registration response rather than the full create/update path. N08 passes its hardened fixture and N11 its final assertions. Cases 01, 05, N02, N09 and N10 retain failed TEST evidence; 03's latest repair was saved but not retested. A RUN_NOT_FOUND result remains unverified.

Automation Coder's four accepted TEST paths are N04's empty-input path, N07's no-shortfall path, and the N12/N13 Calendar tests. They do not establish coverage of all branches. N06 returned a Gmail SENT receipt despite the mocked-only instruction, so its terminal success is not included. Thirteen other drafts retained failed repairs, commonly because the save submitted version 0 against saved version 1. A passing candidate test cannot certify a different persisted draft.

What to fix next

Fix Automation Coder's version-aware persistence first, then test the saved definition after repair. For Workflow Split, close the variable/list mapping and Calendar pagination gaps that keep the four partial cases incomplete. A subsequent comparison should freeze model and configuration, give each approach the same retry budget, and run the same assertions against the final saved artifacts. That would support a full accuracy claim that these historical runs cannot establish.
