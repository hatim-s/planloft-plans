Text to Workflow — one planner, three specialists

The Workflow Planner is the only agent that talks to the user. It resolves ids, checks the platform docs, gets the plan confirmed, then hands a brief to the Builder, Editor, or Tester. Every build or edit is validated by a planner-driven test loop before the user hears "done".
